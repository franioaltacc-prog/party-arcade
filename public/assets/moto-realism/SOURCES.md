# Race soil textures

Brown Mud 02, Poly Haven. CC0 public-domain dedication.
Source: https://polyhaven.com/a/brown_mud_02
License: https://polyhaven.com/license
File metadata: https://api.polyhaven.com/files/brown_mud_02

1K diffuse, OpenGL normal and ARM (ambient occlusion / roughness / metalness) maps, converted to WebP for web delivery. Color is sRGB; normal and ARM are linear data. All files are hosted locally; the game makes no requests to Poly Haven.
